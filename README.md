# OpenPL

IDE de escritorio open source para desarrollo Oracle PL/SQL, alternativa libre a PL/SQL Developer.
Rust + Tauri v2 + React. Windows y Linux.

**Estado:** en beta. Incluye explorador de objetos, editor PL/SQL, consola de comandos,
grilla SQL editable y pruebas de rutinas. Detalle en [docs/ESTADO.md](docs/ESTADO.md).

## Descargar

Usa la versión beta más reciente en [Pre-releases de OpenPL](https://github.com/whiterdev/OpenPL/releases).
