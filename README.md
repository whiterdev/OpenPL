# OpenPL

IDE de escritorio open source para desarrollo Oracle PL/SQL, escrito en Rust (Tauri v2).
Windows y Linux.

## Requisitos

- Oracle Database 12.1 o superior.
- Oracle Instant Client 19 o 21 (64 bits) en el `PATH` (Windows) o `LD_LIBRARY_PATH` (Linux).
- Para compilar: Rust stable; en Windows, Visual Studio Build Tools con C++.
