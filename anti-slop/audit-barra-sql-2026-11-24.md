# Auditoría de las barras SQL

- **PASS automatizado.** Un solo botón **Ejecutar**. **Detener** conserva el texto, el atajo y su estado habilitado durante la carga.
- **PASS automatizado.** **Traer todas** aparece justo después de las pestañas de resultados, conserva el atajo y enfoca la grilla. Las pruebas cubren la carga, la cancelación y los errores.
- **Pendiente, escritorio.** Abrir una ventana SQL y revisar la barra superior. En un resultado con más filas, comprobar la posición de **Traer todas** junto a **Historial**.
